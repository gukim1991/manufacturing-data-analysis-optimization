## 2. 연구 배경 및 필요성

### 2.1 산업적 배경
화장품 OEM/ODM 산업은 전형적인 **다품종 소량생산(High-Mix Low-Volume)** 환경으로, 동일 라인에서 수십 종의 처방(Formula)이 일 단위로 교차 생산된다. 본 프로젝트의 대상이 되는 공장 MES는 다음과 같은 두 단계의 생산 흐름을 가진다.

- **반제품(Bulk) 생산 공정**: 원료 입고 → 시험(QC) → 계량 → 배합(믹서) → 반제품 시험 → 저장조/숙성조 배출
- **완제품(Finished Goods) 생산 공정**: 충전(PLC) → 공정검사 → 완제품 시험 → 포장 입고

각 지시(Job)는 BOM에 따라 **고유한 설비 라우팅**을 가지며, 반제품 시험 합격이 완제품 충전의 전제 조건이 되는 **공정 간 강한 의존성**이 존재한다. 이는 12주차 강의에서 정의한 **Job Shop Scheduling Problem(JSSP)**의 구조와 일치한다.

### 2.2 현장의 문제점
현재 MES는 실행(Execution)과 추적(Traceability) 중심으로 설계되어 있어, **스케줄링은 작업자의 경험과 수기 보드에 의존**한다. 이로 인해 다음과 같은 손실이 반복적으로 관측된다.

1. 믹서/충전기의 idle time 과다 (한 지시 종료 후 다음 지시 투입까지의 공백)
2. 반제품 시험실 병목으로 후공정(충전) 대기 발생
3. 동일 저울에 복수 계량작업이 충돌, 작업자 수동 우선순위 결정
4. 저장조/숙성조 용량 초과로 인한 배출 지연

### 2.3 필요성
강의에서 학습한 **(1) MILP 기반 전역최적화, (2) Dispatching Rules 휴리스틱, (3) DRL + Action Masking** 의 세 가지 접근을 동일한 공장 데이터에 적용·비교함으로써, **현장 운영팀에 제시 가능한 실용적 스케줄링 솔루션**을 도출하는 것이 본 프로젝트의 필요성이다.

## 3. 프로젝트 목표

1. **모델링**: MES 반제품·완제품 공정을 JSSP로 정형화하고 SimPy 기반 이산사건 시뮬레이션 환경을 구축
2. **최적화**: Makespan 및 Tardiness(납기 지각) 최소화를 목적함수로 하는 스케줄링 모델 개발
3. **비교평가**: MILP(Optimal), Dispatching Rules(Heuristic), DRL(Learning) 세 기법의 성능·연산시간·확장성 비교
4. **현장 적용성 분석**: 도출된 스케줄을 간트 차트로 시각화하고, 현행 수기 스케줄 대비 개선율 정량 평가

## 4. 문제 정의 — MES 공정의 JSSP 매핑

### 4.1 Job · Machine · Operation 정의

| JSSP 구성요소 | MES 매핑 |
|---|---|
| **Job (작업)** | 반제품 지시 1건, 완제품 지시 1건 (지시번호 단위) |
| **Machine (기계)** | 저울 m대, 믹서(PLC) m대, 시험실(QC) m라인, 저장조/숙성조 m기, 충전(PLC) m라인, 포장 라인 m개 |
| **Operation (공정)** | 각 지시를 구성하는 개별 처리 단위 (아래 4.2 참조) |

### 4.2 라우팅(Routing) — Job 별 고정 공정 순서

**반제품 Job (Bulk-Job j)**

```
  O_j1 (원료계량 @ 저울)
    → O_j2 (배합 @ 믹서 PLC, 1·2·3차 가동)
      → O_j3 (반제품 시험 @ QC)
        → O_j4 (배출 @ 저장조/숙성조)
```

**완제품 Job (FG-Job k)** — 단, 사전 조건으로 해당 BOM의 반제품 Job 이 `O_j3` 합격 완료여야 함

```
  O_k1 (충전 @ 충전 PLC 라인)
    → O_k2 (공정검사 @ 충전 PLC + QC 인력)
      → O_k3 (완제품 시험 @ QC)
        → O_k4 (포장 입고 @ 포장 라인)
```

### 4.3 제약 조건(Constraints)

강의의 **JSSP 3대 제약**을 본 공정의 추가 제약으로 확장한다.

| 분류 | 제약 |
|---|---|
| ① 작업 선후행 | 각 Job 내 Operation 은 `O_j1 → O_j2 → ...` 순서로만 진행 |
| ② 작업 비선점 | 믹서/충전 PLC 가동(`O_j2`, `O_k1`)은 시작 후 중단 불가 |
| ③ 기계 용량 | 저울·믹서·충전 PLC·시험실은 동시 1 Job 만 처리 |
| ④ BOM 종속 (확장) | `O_k1.start ≥ O_j3.end` (해당 반제품 시험 합격 시점) |
| ⑤ 저장조 용량 (확장) | 동시 저장 가능한 반제품 수 ≤ 저장조 수, 숙성 시간 부여 |
| ⑥ 라벨/스캔 동기 | 5-2 적합 원료 라벨 스캔, 6-4-1 계량원료 라벨 스캔 등은 무시 가능한 처리시간으로 모델링 |

### 4.4 결정 변수 및 목적함수

- 결정 변수
  - $t_{ji}$ : Job j의 i번째 Operation 시작 시점 (연속)
  - $y_{ji, j'i'}$ : 동일 기계에서 (j,i) 가 (j',i') 보다 먼저 처리되는지 여부 (Binary, 0/1)
- 목적함수 (가중합)
  $$ \min \;\; \alpha \cdot C_{max} + \beta \cdot \sum_j \max(0,\, C_j - d_j) $$
  - $C_{max}$ : Makespan (모든 Operation 의 최종 완료 시점)
  - $C_j - d_j$ : Job j 의 납기 대비 지각 (Tardiness)
- 핵심 기법: Either–Or 논리를 위한 **Big-M 제약** (강의 18쪽)
  $$ t_{j'i'} \ge t_{ji} + p_{ji} - M(1 - y_{ji,j'i'}) $$

## 5. 적용 방법론

### 5.1 환경 구축 — SimPy 이산사건 시뮬레이션

강의의 Process-Oriented DES 패러다임을 채택하여 SimPy 로 가상 공장을 구현한다.

| SimPy 자원 | 매핑 대상 |
|---|---|
| `simpy.Resource` | 저울, 믹서 PLC, 충전 PLC, 시험실, 포장 라인 (capacity = 보유 대수) |
| `simpy.Container` | 원료 재고, 저장조의 누적 반제품 용량 |
| `simpy.Store` | 라벨 단위로 식별되는 원료 batch, 반제품 batch (라벨 ID 보존) |

각 Job 은 generator function 으로 정의되어 `yield env.timeout(p)` / `yield resource.request()` 로 자원 점유–처리–해제를 모델링한다.

### 5.2 세 가지 스케줄링 기법 (강의 35~38쪽 매핑)

#### (1) MILP — 전역 최적해 (Pulp / Gurobi)
- 4.4의 정식 모델을 LP 파일로 출력 후 솔버 호출
- 소규모 인스턴스(Job ≤ 10) 에서의 최적 Makespan 확보 — 후속 기법의 **벤치마크**

#### (2) Dispatching Rules — 휴리스틱
- 비교 대상 룰: **SPT** (Shortest Processing Time), **EDD** (Earliest Due Date), **LPT**, **FIFO**, **CR** (Critical Ratio)
- 각 기계 큐에서 즉시 의사결정 → 대규모 인스턴스(Job ≥ 100) 에서도 실시간 가능

#### (3) DRL + Action Masking — 학습 기반
- 상태(State): 각 Job 의 잔여 Operation, 각 Machine 의 잔여 가동 시간, 시험실 큐 길이
- 행동(Action): "어떤 Job 의 다음 Operation 을 어떤 가용 기계에 배정할지"
- **Action Masking**: BOM 종속(④) 미충족, 비선점(②) 위반, 저장조 만재(⑤) 등 무효 행동은 마스킹
- 보상(Reward): $-\Delta C_{max}$ (Makespan 증가분의 음수)
- 알고리즘: PPO (Proximal Policy Optimization), 필요 시 GNN 인코더 결합 (강의 16쪽 Federated Digital Twin 참고)

## 7. 기대 효과

1. **현장 운영 개선**: 현행 수기 스케줄 대비 Makespan O% 단축, 시험실 대기 시간 O% 감소 (정량 검증 예정)
2. **방법론 비교**: 강의에서 학습한 세 기법의 trade-off (정확도 ↔ 연산시간 ↔ 확장성) 를 실 데이터로 검증
3. **재사용 가능한 자산**: SimPy 기반 가상 공장 모델 → 차후 신규 라인 증설 / 신제품 도입 시 What-if 분석에 즉시 활용
4. **학술적 기여**: BOM 종속과 저장조 용량을 포함한 **확장 JSSP** 모델링 사례 제시
